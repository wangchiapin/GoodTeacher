# 遊戲與小工具的讀音，對照字體規則

整理日期：2026-10-25。字體規則是 Release 2026-10-13 版的 `readings.txt`（v10）加 `rules.csv`。

把 Ben 的遊戲與小工具裡「台灣讀音修正表」共 749 個詞，逐詞拿去對字體規則：完全一樣 669 筆，不一樣 93 筆（只有輕聲不同 51 筆，念法真的不同 42 筆）。

**限制**：每個詞是單獨丟進規則檢查，沒有放進整句，所以靠前後文的字（例如「還車」）字體在整句裡可能其實是對的，需要用字體實際打一次確認。
